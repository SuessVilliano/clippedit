# API Notes — verified 2026-08-24

These notes are intentionally dated. Re-check official docs during implementation because APIs evolve.

## Twitch
Official Helix currently provides live stream discovery/current viewer counts and clip discovery by broadcaster/category with date windows. Clip creation and newer clip-download operations require appropriate user/broadcaster/editor authorization scopes.

Architecture consequence: **discovery permission is not the same as media-download permission.**

Official docs:
- https://dev.twitch.tv/docs/api/
- https://dev.twitch.tv/docs/api/reference
- https://dev.twitch.tv/docs/api/clips

## Kick
The official Kick Developer Public API currently exposes livestream retrieval/statistics, user livestreams, channels, categories, event subscriptions, and OAuth/token flows. Validate live schemas and filters during implementation.

Official API:
- https://api.kick.com/swagger/index.html

## Engineering rule
No production adapter should depend solely on this dated note. Validate endpoint schemas and current terms while implementing.
