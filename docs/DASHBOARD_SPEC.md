# Dashboard Specification

## Global navigation
Live, Trending, Emerging, Stories, Creators, Watchlists, Alerts, Studio, Settings.

## Live table
Show platform, creator, title, category, viewers, +5m, +15m, momentum, stream age, and last observed. Default sort: momentum descending, then viewers descending.

## Trending
Panels for streams, clips, and topics. Filters: 1h, 6h, 24h, 7d, platform, topic/category, watchlist.

## Emerging
Surface items that are not yet large by raw reach. Show current audience, baseline audience, acceleration, related creator count, first detected, reason, and confidence.

## Story page
Timeline of first mention, first clip, viewer acceleration, related creator mentions, and peak/current state. AI summaries must link to source records.

## VITURE / operator mode
Optional dense wide layout:
- left: Live Radar
- center: story/clip detail
- right: alerts + watchlist
- keyboard shortcuts
- visible auto-refresh timestamp

This is a UI mode, not a separate data model.
