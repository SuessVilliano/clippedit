# Roadmap

## Phase 0 — Foundation
Repository, Supabase, env vars, CI, Next.js layout, platform adapter interfaces.

## Phase 1 — Live Intelligence MVP
Watchlists, Twitch/Kick live ingest, stream snapshots, momentum scoring, `/live`, creator detail, alerts, ingest health.

**Done when:** a user can add creators and see near-real-time live status plus viewer momentum.

## Phase 2 — Clip Intelligence
Public clip metadata for supported APIs, clip snapshots, views/hour, creator-relative baselines, `/trending`, 24h/7d filters.

## Phase 3 — Emerging Stories
Topic/entity extraction, clustering, cross-creator event detection, `/emerging`, `/stories/[id]`.

## Phase 4 — Creator Studio
Creator connections, scope tracking, own-content workflow, stream markers, authorized clip operations, Opus export, approval queue.

## Phase 5 — Distribution
TradeHybrid.tv webhook, social destinations, publish queue, analytics feedback.

## Phase 6 — Marketplace
Clip bounties, editor profiles, submissions, performance tracking, payments, platform fee.

## Phase 7 — Network Intelligence
Large discovery universe, creator discovery, sponsor/brand dashboard, public API, enterprise alerts.
